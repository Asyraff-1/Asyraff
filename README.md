# AetherPulse

A production-grade, interactive IoT Fleet Telemetry & Edge Intelligence Platform. Built with Next.js 14, TypeScript, Tailwind CSS, and Lucide React.

## Features

- **Real-Time Telemetry Simulation**: Client-side stream generator simulating live IoT data (Power, Environmental, Spatial) every 1.5 seconds.
- **Executive Dashboard**: Aggregate metrics, spatial radar canvas, multi-axis telemetry charting, and active node quick grids.
- **Fleet Management**: Comprehensive tabular view of edge devices with filtering and pseudo device registration capabilities.
- **Alert Rules & Incident Log**: Chronological incident feed and rule builder visualizers for threshold tracking.
- **Industrial Dark Theme**: Styled with a highly readable Slate and Emerald palette using Tailwind CSS.

## Architecture

- **Framework**: Next.js App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts

## Getting Started

1. **Install Dependencies**
   `npm install`

2. **Run Development Server**
   `npm run dev`
   Navigate to `http://localhost:3000`.

3. **Build for Production**
   `npm run build`
   `npm run start`
